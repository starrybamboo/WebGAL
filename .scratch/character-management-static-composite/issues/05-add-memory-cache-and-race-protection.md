# 05 — 实现非阻塞内存缓存与异步竞态保护

**What to build:** 在当前游戏进程内复用角色模板和组合结果，并保证加载、快进和连续换装时只有角色的最新请求可以改变舞台，同时不引入任何持久化缓存。

**Blocked by:** 03 — 支持有序组合列表与递归预设；04 — 以角色身份更新 figure 演出状态

**Status:** ready-for-agent

- [ ] 已校验模板、已生成组合和进行中的同键任务在当前游戏进程内复用。
- [ ] 相同模板和相同最终展开序列的并发请求共享一个准备任务，不重复加载或合成。
- [ ] 缓存与游戏进程同寿命，不写入 IndexedDB、`localforage`、磁盘或持久化 WebP。
- [ ] 模板、部件或组合尚未就绪时，剧本、自动播放和快进流程仍然继续。
- [ ] 同一角色的新请求能够使旧请求失去舞台写入资格；旧任务完成后不得覆盖最新组合。
- [ ] 失败结果不会永久占据缓存，资源或模板修正后可以再次请求。
- [ ] 实际可见请求优先于未开始的预热任务，相同键的可见请求能够复用已经开始的预热。
- [ ] 测试通过可控异步顺序验证任务合并、失败重试和旧结果隔离，不依赖私有缓存容器结构。
