# 09 — 完成兼容性与交付验收

**What to build:** 完成角色组合工作流的跨模块验收，并修复最后的兼容性缺口，使新功能可以在不改变既有 figure 行为的前提下交付。

**Blocked by:** 06 — 保存并非阻塞地恢复角色舞台；08 — 在 Terre 生成 character 命令并同步预览

**Status:** ready-for-agent

- [ ] 完整场景能够定义角色模板、显示角色、切换组合、移动角色、快进、存档并非阻塞地读档恢复。
- [ ] 既有普通图片、Live2D、Spine `changeFigure` 的解析、资源识别和舞台行为保持原样。
- [ ] `figure.json` 角色模板不会被普通 figure 或 Live2D 路径处理，组合输出始终按普通图片进入 figure。
- [ ] 仓库中没有 `composeFigure`、`-composite` 的有效实现或兼容分支，也没有引入持久化缓存依赖和设置项。
- [ ] Web 运行时与 Terre 预览完成端到端验收；现有 Electron 和移动端资源路径在其既有构建验收范围内通过。
- [ ] 角色唯一性、预设展开、缓存命中、异步竞态、失败重试和读档恢复均有外部行为测试覆盖。
- [ ] 受影响包的测试、类型检查和构建通过，普通 figure 回归用例保持绿色。
- [ ] 用户可见语法、模板字段和已知非目标与本地 Spec 保持一致。
