# 02 — 打通单部件 character 立绘

**What to build:** 让剧本作者可以通过 `character` 命令显示一个由单个静态部件组成的角色；引擎读取角色模板、生成普通图像并交给既有 figure 舞台，全程不把模板 JSON 当作 figure 资源。

**Blocked by:** 01 — 删除私有立绘合成遗留代码

**Status:** ready-for-agent

- [ ] 场景解析器能够识别 `character`，并保留角色名、单个组合项和现有 figure 参数。
- [ ] 最小合法角色模板可以声明版本、组合画布和一个静态部件，部件路径相对角色目录解析。
- [ ] 执行单部件角色命令后，角色最终作为一张保留透明通道的普通图片显示在指定舞台位置。
- [ ] 模板读取和图片准备不阻塞剧本继续执行，资源完成后角色能够正常显示。
- [ ] `figure.json` 从未进入普通 figure URL 或 Live2D 类型判断。
- [ ] 一条完整场景语句能够通过高层测试验证角色状态和最终 figure 交付结果。
- [ ] 既有 `changeFigure` 解析和运行时行为不受新增命令影响。
