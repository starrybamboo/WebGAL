# 08 — 在 Terre 生成 character 命令并同步预览

**What to build:** 让作者在 Terre 中选择角色和有序组合项、生成正式 `character` 语句，并在模板保存后无刷新地看到舞台角色更新。

**Blocked by:** 04 — 以角色身份更新 figure 演出状态；05 — 实现非阻塞内存缓存与异步竞态保护；07 — 在 Terre 编辑并预览最小角色模板

**Status:** ready-for-agent

- [ ] 命令编辑界面能够选择角色、排序部件或预设、保留重复项，并编辑适用的 figure 参数。
- [ ] 生成结果采用 `character: <角色名>/<组合项>[,<组合项>...]` 语义，不生成 `-preset`、`-composite` 或组合版 `changeFigure`。
- [ ] 生成的语句能够被当前预览引擎解析并显示正确角色组合。
- [ ] 保存某个角色模板后，只失效该角色的模板和组合缓存，不清空无关角色缓存。
- [ ] 舞台上正在使用该模板的角色会异步重建，预览页面和游戏流程不会刷新或阻塞。
- [ ] 连续保存和连续切换组合时，较旧的预览结果不会覆盖最新模板状态。
- [ ] 首期界面不提供尚未定义的局部组件变体切换命令。
- [ ] 测试覆盖命令生成、解析往返、定向缓存失效和无刷新预览更新。
