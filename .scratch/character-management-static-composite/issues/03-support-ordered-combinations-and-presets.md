# 03 — 支持有序组合列表与递归预设

**What to build:** 让作者可以在 `character` 选择符中混合书写多个部件和预设，并按照明确、可验证的展开顺序合成完整静态角色立绘。

**Blocked by:** 02 — 打通单部件 character 立绘

**Status:** ready-for-agent

- [ ] 斜杠后的逗号分隔组合项按作者书写顺序处理，每项可以引用部件或预设。
- [ ] 预设可以在引用位置递归展开其他预设，最终展开顺序就是 `source-over` 绘制顺序。
- [ ] 重复引用不会被隐式去重，每次引用都会产生对应图层。
- [ ] 部件的 `x`、`y` 和等比 `scale` 按组合画布坐标应用，越界像素在画布边界裁剪。
- [ ] 缺失引用、循环引用、空展开结果、非法数值和越出角色目录的资源路径会产生作者可诊断的模板错误。
- [ ] 无效组合不会以部分结果替换角色当前立绘，后续修正后的相同请求可以重新尝试。
- [ ] 测试覆盖部件与预设混用、嵌套展开、重复项、绘制顺序以及主要错误分支。
