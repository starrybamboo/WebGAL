# 06 — 保存并非阻塞地恢复角色舞台

**What to build:** 让包含组合角色的舞台能够被可靠保存和恢复；读档立即恢复游戏流程，并在后台重新准备每个角色的普通图像。

**Blocked by:** 04 — 以角色身份更新 figure 演出状态；05 — 实现非阻塞内存缓存与异步竞态保护

**Status:** ready-for-agent

- [ ] 存档保存角色名、作者原始组合列表、位置和必要的 figure 演出状态。
- [ ] 存档不保存 Blob URL、Canvas、Pixi 纹理、Promise 或其他仅在当前进程有效的对象。
- [ ] 读档提交逻辑角色状态后立即继续游戏，不等待模板、图片或组合完成。
- [ ] 组合准备完成后，只在该角色仍对应相同恢复请求时应用图像。
- [ ] 单个角色模板、资源或合成失败不会中止其他舞台对象恢复，也不会阻塞后续剧本。
- [ ] 不包含角色状态的旧存档继续按照既有规则恢复。
- [ ] 测试覆盖缓存命中、缓存未命中、失败隔离和读档后立即推进剧本的行为。
