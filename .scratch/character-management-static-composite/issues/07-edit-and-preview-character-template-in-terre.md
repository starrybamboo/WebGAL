# 07 — 在 Terre 编辑并预览最小角色模板

**What to build:** 让作者能够在 Terre 中创建和维护角色模板，并使用真实引擎规则预览静态组合结果，而无需手工计算画布和部件位置。

**Blocked by:** 03 — 支持有序组合列表与递归预设

**Status:** ready-for-agent

- [ ] Terre 能够把角色目录中的 `figure.json` 识别为角色模板资源，而不是普通 figure 或 Live2D 文件。
- [ ] 作者可以编辑模板版本、组合画布、静态部件资源、`x`、`y`、`scale` 和有序预设引用。
- [ ] 编辑器支持角色目录内的静态位图和子目录资源，并拒绝非法路径与不支持的资源类型。
- [ ] 预览使用与运行时一致的展开、顺序叠加、重复项、裁剪和错误规则。
- [ ] 无效模板在保存前给出可定位的作者错误，不进行隐式修复。
- [ ] 编辑器能够加载既有合法模板、保存后重新打开，并保持作者声明的数组顺序。
- [ ] 测试从作者操作观察保存结果和预览结果，不依赖编辑器内部组件层级。
