# 04 — 以角色身份更新 figure 演出状态

**What to build:** 让 `character` 始终以角色名操作稳定的舞台对象，使作者能够更新组合、位置、变换、效果和动画，而不会创建第二个同名角色。

**Blocked by:** 02 — 打通单部件 character 立绘

**Status:** ready-for-agent

- [ ] 同一舞台上最多存在一个同名角色，重复命令更新已有角色而不是追加实例。
- [ ] 不同角色拥有彼此独立的身份和舞台状态，即使它们使用相同位置或相同组合资源。
- [ ] 已存在角色省略组合列表时保持当前组合，只应用本次显式提供的 figure 参数。
- [ ] 首次调用未提供组合列表时记录作者错误，不创建不完整的角色实例。
- [ ] 更换组合列表时角色身份保持不变，新组合最终替换该角色当前普通图像。
- [ ] 静态图片 figure 的位置、transform、ease、时长、进出场动画、zIndex、blendMode 和适用效果可由 `character` 使用。
- [ ] 测试覆盖同名更新、不同角色并存、角色移动、组合切换和 figure 参数应用。
