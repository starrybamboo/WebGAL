# 采用 character 角色管理方向并撤回首期持久化与阻塞读档

根据 WebGAL Issue #1010 的仓库成员评论和后续讨论，正式入口改为以角色名为唯一身份的 `character` 命令，并采用 `character: <角色名>/<组合项>[,<组合项>...];` 直接选择有序组合，不使用 `-preset` 参数。组合结果作为普通图像进入现有 figure 系统；首期不实现浏览器持久化缓存，组合加载与读档沿用普通立绘的非阻塞流程。此前 ADR 中要求扩展 `changeFigure`、允许同角色多目标、实现持久化缓存或等待组合完成后再继续读档的内容均由本决策覆盖，只保留为历史讨论记录；组件组与变体仅记录为后续方向，具体语义待讨论。
