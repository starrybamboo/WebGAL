# 允许组合预设声明独立画布

角色名继续作为稳定的舞台身份，但画布不再归属于整个角色。对象形式的组合预设可以用 `{ "canvas": { "width": ..., "height": ... }, "items": [...] }` 声明自己的合成画布，使同一角色的每个立绘组都能采用该组默认底图的裁剪后尺寸，并在其上按槽位叠加头像等部件。

模板顶层 `canvas` 保留为直接部件选择和旧数组预设的兼容回退。一次组合选择若展开出多个不同的预设画布则视为模板错误；组合缓存键必须包含最终解析出的画布，避免相同图层名称在不同尺寸下错误复用结果。合成后的普通图像仍交给 figure 系统处理舞台缩放、裁剪、位移、滤镜和动画。
